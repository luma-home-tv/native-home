# G2 retained native preview, 0.47

The G2 now retains the ordinary **0.47.0 preview** after two fresh native sessions
completed successfully. The final operator exited 0 with the full installed
bundle, original private preferences and 20 preservation domains verified.
The six earlier failed operators remain exit 1. This is a retained standalone
preview; LG Home remains the system home.

The [sanitized milestone](g2-retained-preview047-milestone.json) records the
execution and scope. An independent saved-evidence audit and a separate Root
replay both exited 0, with byte-identical reports.

## What was delivered and observed

The package contains 32 bundle entries and 30 files. All 28 resources from the
[retained 0.37 installation](retained-preview-037.md) are byte-identical; only the
executable and application version metadata changed. The tested executable is
frozen at functional source `be6c06a341d72be1d06e92819a1be6c71ed52048`, with 101
selected build inputs. This is the retained frozen artifact; later documentation
revision `473626` and subsequent 0.48 source work do not acquire its compiled or
native qualification.

Both fresh sessions used independently bound ordinary processes and the native
Home → Apps → Home → Back flow. The first included a 125-second no-input idle
checkpoint, one Up wake, then a natural Back exit. Its compositor image had a
dark-pixel fraction of **1.0** and mean RGB **0.0**. Native receipts recorded one
idle presentation/wake in the first session and none in the second. Both loaded
and read back the original initialized preferences, queued zero preference
content writes, performed live catalogue reads and recorded no app-card,
settings or input-source actions. Neither session opened a keyboard.

Root reviewed native frames showing the Luma logo and available icons without
an added surrounding graphite plate. This is visual evidence for those frames,
not an inventory of uploaded textures or all-app artwork coverage. The shared
native foundation remains the attributed
[PlxNative framework](../README.md#plxnative-framework-dependency).

Root's current-frame commands allowed Apps-rail OK only after a matching whole
compositor image less than five seconds old. That is a sampled input guard,
not an atomic focus/key-delivery guarantee. Physical remote input, IME,
performance, Root artwork and comprehensive TV functionality are not qualified
by this run.

no TV permission repair or preference content rewrite was used to make the
carrier pass; its frozen application binary remained unchanged.

## Preservation and cleanup

Final readback matched the full retained 0.47 bundle and every original
preference byte and metadata field. Five Core-file digests and 19 typed read
domains matched the baseline. Six verified own staging/capture directories were
removed, the lease was released and the private host agent was cleaned up with
no recorded errors. Runtime receipt directories were intentionally retained;
preexisting runtime contents were not rehashed or claimed absent.

The saved audit checks 18,769 assertions across 1,670 bound artifacts and 15
compositor frames. Those counts are not a coverage or performance score. Its
version 4 rejected an execution-log mode assumption; version 5 passed the
component audit with 18,767 assertions; version 6 then rejected an incorrect
private-parent assumption. Version 7 records the actual evidence-directory
`0755` and attested execution-log `0644` modes. Critical backups and frame inputs
remain `0400/0600`, but an entirely private host enclosing directory is not
qualified. All audit versions and failures are preserved; these saved-only
corrections required no TV rerun. No raw images or personal state are published.

This record supports the bounded two-session retained preview. It does not
replace the separate [C2 native-trial/restoration record](c2-native-preferences-047.md),
qualify C2 migration, or enable Root artwork startup. Further lifecycle, broader
settings and artwork coverage remain implementation work.
