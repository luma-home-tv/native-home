diagnostic package. The original operator exited 1 and remains a failed trial.
It never reached explicit dashboard launch, privileged helper staging or cache
population. C2 was not contacted. No native cache or performance qualification
follows this attempt.

The original installer subscription contains 21 complete frames and exactly one
matching `installed` terminal with status 30. Independent saved-stream replay
found no framing, truncation or service failure. The operator rejected the normal
SSH PTY connection-close message following the known SSH warning. Installation
had completed; retrying that diagnostic installation was unnecessary.

original private preferences and Host runtime, sampled Core state, whole Preview

cache aliases absent. This does not establish absence in every possible namespace.
