# C2 retained normal preview 0.48

C2 now retains normal 0.48.0. Two fresh processes from the same already updated
installation completed Home → Apps → Home → Back, with a 125.972-second no-input
idle/wake in the first session. The operator exited zero, and an independent
saved-evidence audit passed. Root replayed the unchanged auditor successfully
and obtained a byte-identical report, recorded in the
[milestone](c2-retained-preview-048-milestone.json).

The frozen build is source `cba8196ba66763f959bb50b5b1193d114de7d880`, with
101 selected inputs. Dashboard SHA-256 is
`b8e0ac9b3918c354a3fc1a7068c404a4a61d155318807f30e027b0aa130962d3`.
The normal package preserves all 38 original C2 resource files: only the
executable and app version change within the 42-entry, 40-file bundle. It
contains no migration/artwork diagnostic marker or Root helper. G2 assets and
synthetic fixtures were not substituted.

The ordinary Preview identity first completed a forward/reverse metadata
roundtrip and exact old 0.20 restoration. Its original failed forward operator
remains a failure; the separately admitted continuation qualified the saved
forward result, reverse transaction and restoration. The final normal upgrade
used a fresh forward migration. Only the two own-state permission modes changed
to private `0700`/`0600`; all 216 preference bytes, favourites and ownership
remain equal to the original backup. The old 0.20 records remain historical,
rather than a description of the current installation.

Seventeen compositor frames and fifteen closed commands bind the two new
sessions. Apps-rail OK required a fresh complete-image match within five seconds
of capture request; this is a sampled guard, not atomic focus proof. No app card,
source, setting or text-entry action was exercised. The idle interval contained
no injected key, sampled the same process/window, and produced a captured frame
with dark fraction 1.0 and mean RGB 0.0. One arrow woke the app; native idle/wake
counters were one/one in session one and zero/zero in session two. These are
app/compositor observations, not panel-power measurements.

Both sessions loaded the original preferences, queued no content writes and
recorded nonsimulated catalogue reads. Full final bundle/state byte and metadata
checks, twenty preservation domains and five Core hashes passed. Four owned
staging uploads, their directory and captures were removed; the owned lease and
private agent closed. The measured shared sticky runtime parent and two normal session logs
are intentionally retained. Historical runtime contents were not deeply rehashed;
there is no runtime-absence claim.

The initial normal operator failed on duplicate host evidence before normal UI
launch. One later continuation stopped before UI because power was not literal Active;
another stopped after one LG Home acknowledgement when bounded observation
still reported Screen Saver. Neither retried that guard or qualified a session.
Their exit-one outcomes remain intact. Only the final two fresh sessions support
the normal-UI result. Earlier installer/migration and missing-report histories
are preserved in the [C2 upgrade plan](c2-retained-upgrade-plan.md) and
[earlier native trial](c2-native-preferences-047.md).

The independent audit replays raw process records, historical build/package
bindings, frames/commands, complete saved trees and closeout evidence. Its
126,576 named checks and 23,090 file bindings are bookkeeping, not coverage or
performance scores. No native process exit status was measured directly; natural
Back terminal content and subsequent identity absence were observed. Audit
repair history is retained with the private evidence; it does not change device
outcomes.

Normal Root artwork remains off. Actual packaged-artwork views do not establish
