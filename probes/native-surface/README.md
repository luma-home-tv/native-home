# Ordinary held native surface prerequisite

This separate Cargo workspace preserves the minimal ordinary held-window probe.
It is not the dashboard, an artwork provider, a Root helper or a TV operator.
Its fixed application is `com.ash.nativehome.proof`, version0.1.0, executable
`surface-scene-proof`. The same identity must be wholly absent before a future
separately admitted installation; there is no adoption/relaunch workflow here.

The main, scoped SDL/GLES runtime, identity adapter and C SDL-event shim are exact
frozen source copies of the historical private V2 proposal. Their original
source basis is `324d016a248d8c5d84b0b4fe89766d79bf3b54c5`. The manifest records
that basis, the copied-file hashes, the publication base and actual current
framework/build inputs. These source constants are provenance, not device
qualification or app-role authority. No application input policy was changed
for publication.

After a successful native Window creation, the probe draws black while eligible
and holds that Window for60seconds, continuing to poll. Observed focus loss or
hiding permanently stops clears and swaps; focus gain never resumes them.
Pointer motion also stops rendering. Discrete input, Quit, unknown events or a
full256-event batch request an early courtesy abort. The two existing pure
render-gate tests cover those boundaries. The lifetime begins after Window
initialization and is not a hard bound on blocked SDK or teardown calls.

Fixed Ready and Complete JSON metadata is created with exclusive/nofollow0600
opens under a new owned0700 `surface-scene-<actualPID>` leaf beneath
`/tmp/com.ash.nativehome.proof`. The shared framework parent is distinct from
that private leaf and is1777. Before framework initialization the source refuses
foreign/symlink/nonsticky or private700 existing parents; it does not repair them.
The native identity and owned executable observation must agree with independent
live kernel evidence. Arguments and environment select no app, path, URI, hold,
operation or policy. No Target launch, LS2/HBC, preferences, account, settings,
artwork, keyboard request, subprocess or application worker is added.

Ready is written after the first frame, including an abort/no-swap first frame.
Complete distinguishes full_lifetime_unaborted/fixed_lifetime_complete from
courtesy_abort and is written while the Window remains owned; ordinary Drop then
follows. A sparse window_initialization_failed result is not a scene success.
Neither receipt measures an OS exit code or SDK internal threads/activity.
Actual foreground, soleCARD composition, renderer departure, both actors and
external closure remain a separate coordinator's evidence. This probe's source
never starts the existing fixed12-second `launch-target` application.

`build-arm.py` has the existing presence-based compiler-override guard. It checks
the admitted source manifest and unchanged34-package seeded/pruned production-
subset lock before and after a locked offline build in a fresh private output.
It verifies the attributed framework and records the SDK compiler, three compiled
C objects (SVG, ARM32 getauxval compatibility and SDL events), exact flags,
object continuity and ELF. Cargo/framework paths are repository-relative; Root
must preserve this directory in Git before building. No framework source copy
or upstream substitution is introduced. The framework is PlxNative by Gleb Linnik
and contributors, revisiond507c4f9ed5b4ecd88ce9b2e998c50da506e6271, with the
project's explicitly recorded integration patch and GPL-3.0-or-later licence.

`package-native-surface.py` is a local archive builder, not a deployment script.
It requires the reviewed manifest/build receipt and actual ELF. The new package
contains exactly six files: executable, appinfo, icon, the project's two fonts
and their OFL licence. These font bytes are explicitly bound as external source
inputs so the unchanged eager text initializer can load owned known fonts rather
than depend on a system-font fallback. The probe still draws no text. Packaging
fonts changes the package, not the Window class or gate, and does not establish
identical startup timing, rendering or performance. There are no requested
permissions, services, hooks, Root configuration or test-selector markers.
